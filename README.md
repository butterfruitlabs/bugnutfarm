# Bugnut Farm Ciderhouse

The website for Bugnut Farm Ciderhouse, a small orchard and farm cidery in Walden, New York, making dry, sparkling, French-style cider from estate-grown cider apples.

Live at **[bugnutfarm.com](https://bugnutfarm.com)**, hosted on GitHub Pages.

## What's here

| File | Purpose |
| --- | --- |
| `index.html` | The entire website, a single self-contained page. The photos, banner and apple favicon are embedded directly in the file, so there are no other assets to manage. |
| `CNAME` | Connects the custom domain bugnutfarm.com to GitHub Pages. **Do not delete.** |
| `README.md` | This note. |

## Updating the site

**Text** (cider details, pairings, where to drink it, etc.): open `index.html` on GitHub, click the pencil icon, find the text you want to change, edit it, and commit. The site updates within a minute or two.

**Photos:** images are embedded inside `index.html` as encoded data, so they can't be swapped by uploading a new image file. To change a photo, rebuild the page with the new image, then upload the new `index.html` in place of the old one.

## Page sections

1. Header: banner wordmark and navigation
2. Intro: "Cider from cider apples" and the orchard photo
3. The ciders: Rosalie, Lucie and Babette, with style, alcohol, apple varieties and pairings
4. The farm: the barn and the orchard's story
5. In the orchard: fruit photos and the list of varieties grown
6. Where to drink it: current New York City accounts
7. Trade: contact button (hello@bugnutfarm.com), distribution and formats
8. Footer: location and Instagram (@bugnutfarm)

## Details

- Fonts are loaded from Google Fonts (Cormorant Garamond, EB Garamond, IM Fell English SC and Jost). The browser falls back to standard serif fonts if they can't load.
- There are no scripts, tracking, cookies or external libraries.
- The layout works on phones, tablets and desktops.
- Trade email forwarding for hello@bugnutfarm.com is set up through Namecheap, the domain registrar.
